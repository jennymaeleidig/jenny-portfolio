# jenny-portfolio

Jenny Leidig's portfolio: a static site at `https://portfolio.jenny-page.online`, replacing `jennyleidig.straw.page`.

It is not built yet. The design is decided and the build is specified.

## Where the decisions are

- **[Wayfinder: jenny-portfolio](https://github.com/jennymaeleidig/jenny-portfolio/issues/1)** is the map: the destination, and one line per decision with a link to the ticket that holds its detail. Seventeen decisions, all closed.
- **[Build the site: static portfolio on a monospace grid](https://github.com/jennymaeleidig/jenny-portfolio/issues/20)** is the spec: what gets built, the seams it is tested at, and what is out of scope.

Read the map to understand *why*, the spec to understand *what*.

## What it will be

- `/` with six featured projects, `/work` as the catalogue, `/projects/<slug>` for a single project.
- `/resume` as the complete record, with `/resume.pdf` and `/resume.md` exported from it.
- `/about` and `/now`.
- Content is one markdown file per project with YAML frontmatter.
- Generated by [jenny](https://github.com/hmngwy/jenny) from vendored bash, deployed by GitHub Actions to Pages.
- Monospace character grid, warm paper, a slow pixelated sky behind it.

## What is here now

- `prototype/` — a throwaway artifact on the branch `prototype/shader-background`, settling how the sky is drawn and tuned. **Never merged.** Its markup is not carried over; the values it produced are recorded in the ticket.
- `docs/agents/` — how issues, labels and domain docs work in this repo.

## Local development

Nothing to run yet. The build target, tests and deploy workflow arrive with the spec.
